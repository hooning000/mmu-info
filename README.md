# 해양대 정보 (비공식)

국립목포해양대학교 승선생활관 식단, 해성공지, 승선사관부 공지를 폰에서 쉽게 보는 **비공식** 웹앱이에요.
정확한 내용은 반드시 [학교 홈페이지](https://www.mmu.ac.kr)에서 확인하세요.

- 앱 주소: https://hooning000.github.io/mmu-info/
- 데이터는 3시간마다 자동 갱신돼요 (GitHub Actions).

## 내 컴퓨터에서 실행
```bash
npm run update   # 학교 사이트에서 데이터 받기
npm start        # http://localhost:8000
```
